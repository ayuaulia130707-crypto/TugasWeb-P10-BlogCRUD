# TugasWeb-P9-LaravelSetup

Project ini dibuat untuk memenuhi tugas Pertemuan 9 Pemrograman Web dengan menggunakan Laravel.

## Deskripsi

Project ini merupakan latihan dasar Laravel yang mencakup routing, Blade View, dynamic data, controller, model, migration, dan koneksi database MySQL.

## Fitur

- Halaman Beranda
- Halaman About
- Halaman Contact
- Menampilkan data dinamis menggunakan Blade
- Routing Laravel
- Controller
- Model dan Migration
- Database MySQL

## Cara Instalasi

1. Pastikan PHP dan Composer sudah terinstall.
2. Clone atau download project.
3. Masuk ke folder project:

cd TugasWeb-P9-LaravelSetup
